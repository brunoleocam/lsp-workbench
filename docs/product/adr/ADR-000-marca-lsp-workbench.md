# ADR-000 — Marca LSP Workbench

## Status

Aceito (2026-09-16)

## Contexto

Nomes genéricos (“lsp”, “LSP – Senior…”) já existem no Marketplace e colidem com “Language Server Protocol”.

## Decisão

Marca-guarda-chuva **LSP Workbench**; artefatos `lsp-workbench`, `lsp-workbench-agent`, `lsp-workbench-demobile`.

## Consequências

Ids e pastas alinhados; subtitle enfatiza kit completo vs só colorização.
