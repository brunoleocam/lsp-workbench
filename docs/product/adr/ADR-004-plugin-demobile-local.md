# ADR-004 — Plugin Demóbile só local

## Status

Aceito

## Decisão

**LSP Workbench Demóbile** não publica no Marketplace. Install: junction em `%USERPROFILE%\.cursor\plugins\local\lsp-workbench-demobile`.

## Consequências

Dados internos ficam fora do git público; time Demóbile sincroniza pasta por meio interno.
